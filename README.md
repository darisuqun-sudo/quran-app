# قۇرئان كەرىم ئەپ مەركىزى (Quran Karim App)

زامانىۋى، تولۇق ئىقتىدارلىق، نەپىس ئىسلامىي ئۇسلۇبتىكى قۇرئان كەرىم ئەپ دېتالى (Flutter Cross-Platform: Web, Android, iOS, Windows, macOS).

---

## 📖 ئالاھىدىلىكلىرى (Features)

- **قۇرئان كەرىم ۋە ئۇيغۇرچە تەرجىمىسى (تولۇق مۇھەممەد سالىھ تەرجىمىسى)**: 114 سۈرە ۋە 6,236 ئايەت تولۇق، ئېنىق، توغرا UTF-8 شەكىلدە يەرلىك (offline) ساقلانغان.
- **604 بەتلىك ئەنئەنىۋى مۇسھەف (Mushaf 604 Pages)**: رەسمىي مەدىنە مۇسھەپ نۇسخىسى بويىچە 604 بەتلىك ھەقىقىي كۆرۈنۈش. 3 خىل كۆرۈش شەكلى:
  1. *مۇسھەف كۆرۈنۈشى*: پۈتۈن بەتلىك ئالتۇن ھەللىك ئېسىل كۆرۈنۈش.
  2. *قوشۇلما كۆرۈنۈش*: ئەرەبچە مۇسھەف تېكىستى ۋە ئاستىدا ئۇيغۇرچە تەرجىمىسى.
  3. *كارتىلار كۆرۈنۈشى*: ھەر بىر ئايەت ئايرىم سۈزۈك كارتىدا.
- **ئۈزلۈكسىز ئاۋاز تىلاۋىتى (Continuous Audio Engine)**:
  - ئايەت ئاخىرلاشقاندا ئاپتوماتىك كېيىنكى ئايەت ۋە سۈرىگە ئۆتۈش.
  - داڭلىق قارىئىلار: مىشارى راشىد ئەلئەفاسى، مەھمۇد خەلىل ئەلھۇسەرى، ئابدۇلباسىت ئابدۇسسەمەد، ئابدۇراھمان سۇدەيس.
- **ناماز ۋاقىتلىرى ۋە قىبلە كومپاسى**:
  - سۈرىيە شەھەرلىرى (دەمەشق، ھەلەب، ھىمس، لەتاقىيە، دېر ئەززۇر، ھەما)، تۈركىيە، سەئۇدىي ۋە دۇنيانىڭ ھەرقايسى جايلىرى ئۈچۈن ناماز ۋاقتى.
  - ئەقلىي ئىقتىدارلىق ئورۇن بايقاش (Auto Location Detection).
- **ئارقا سەھنە باشقۇرۇش مەركىزى (Premium Admin Console)**:
  - سىستېما سىنىقى (Diagnostics), 114 سۈرە ۋە ئايەتلەر مەركىزى، قارىئىلار سىناق پونكىتى، شەھەرلەر تىزىملىكى، خەتكۈچ ۋە تەڭشەكلەرنى JSON ھالەتتە زاپاسلاش (Backup & Export).
- **خەتكۈچ ۋە ئوقۇش خاتىرىسى (Bookmarks & Reading Progress)**.

## 🛠️ ئېچىش ۋە قاچىلاش (Development & Setup)

### ئالدىنقى شەرتلەر (Prerequisites)
- [Flutter SDK](https://flutter.dev) (3.x ياكى ئۇنىڭدىن يۇقىرى)
- [Node.js](https://nodejs.org) (ياردەمچى تور سەرۋىرى ۋە پىرىسلاش ئۈچۈن)

### ئىجرا قىلىش (Run App)
```bash
# تايىنىشچان بولاقلارنى چۈشۈرۈش
flutter pub get

# تەھلىل قىلىش ۋە سىناش
flutter analyze

# چاقىرىش (Web دە ئىجرا قىلىش)
flutter run -d chrome
```

### تور نەشرىنى تارقىتىش (Build Web Release)
```bash
# Release قىلىپ تۈزۈش
flutter build web --release

# مەلۇمات ۋە رەسىملەرنى بىرىكتۈرۈش
node scripts/copy_surah_images.js
node scripts/copy_assets.js
node scripts/build_quran_utf8.js

# توردىكى كۆرۈنۈشنى كۆرۈش
node scripts/serve_web.js
```
